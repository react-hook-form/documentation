## Data and submission

- [Editing saved data](/advanced-usage/editing-saved-data): load a record, keep the user's edits, and save what changed.
- [Handling server errors](/advanced-usage/server-errors): map API validation errors onto fields and report failed requests.
- [Multi-step forms](/advanced-usage/multi-step-forms): collect one typed payload across steps, with saved drafts and server validation.
- [Server Actions](/advanced-usage/server-actions): validate on the client, then submit with `useActionState`.
- [Transform and parse](/advanced-usage/transform-and-parse): convert between input strings and the types you store.

## Dynamic fields

- [Conditional fields](/advanced-usage/conditional-fields): show, hide, and validate fields based on other answers.
- [Controlled and uncontrolled inputs](/advanced-usage/controlled-and-uncontrolled): mix native inputs with controlled UI components.
- [Virtualized lists](/advanced-usage/virtualized-lists): keep values and validation for rows that are not mounted.
- [Opaque types](/advanced-usage/opaque-types): treat Dayjs, Decimal, and other class values as single fields in TypeScript.

## Reusable components

- [Smart form component](/advanced-usage/smart-form-component): a `Form` component that wires registration into its children.
- [Connect form](/advanced-usage/connect-form): reach form methods from deeply nested inputs.
- [Error messages](/advanced-usage/error-messages): render validation messages consistently.
- [Custom resolver](/advanced-usage/custom-hook-with-resolver): write a resolver for any validation library or hand-written rules.

## Performance

- [Isolating form subscriptions](/advanced-usage/isolating-subscriptions): re-render only the components that display a value.
- [FormProvider performance](/advanced-usage/formprovider-performance): keep context consumers from re-rendering on every change.

## Quality

- [Accessibility](/advanced-usage/accessibility): labels, error announcements, and focus management.
- [Testing forms](/advanced-usage/testing): test validation and submission the way users interact with the form.
