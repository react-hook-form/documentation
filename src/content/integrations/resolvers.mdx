The [`@hookform/resolvers`](https://github.com/react-hook-form/resolvers) package connects external validation libraries to [`useForm`](/docs/useform). A resolver receives the complete form values, validates them against a schema, and returns normalized values and errors.

## Installation

Install React Hook Form, the resolver package, and your chosen schema library:

```bash
npm install react-hook-form @hookform/resolvers <validation-library>
```

Every adapter follows the same integration pattern:

```tsx
import { useForm } from "react-hook-form"
import { libraryResolver } from "@hookform/resolvers/library"

const form = useForm({
  resolver: libraryResolver(schema),
})
```

## Resolver options

Resolvers accept an optional third argument:

```tsx
resolver(schema, schemaOptions, {
  mode: "async", // or "sync"
  raw: false,
})
```

- Async mode is the default. Use `sync` only when the schema performs no asynchronous work.
- Set `raw: true` when submitted values should remain unparsed instead of using the schema's transformed output.
- Pass a form value type to `useForm` when the comparison table says inference is unavailable.

For detailed working examples, see the dedicated [Zod guide](/integrations/zod) and [Yup guide](/integrations/yup). The [official resolvers repository](https://github.com/react-hook-form/resolvers) maintains quick starts for every adapter.
